Connect your Firebase project

OurTube is a real, Firebase-powered platform. Paste your project credentials into the marked config section at the top of index.html to begin.

1Create a project at console.firebase.google.com and add a Web App.
2Enable Authentication → Google sign-in provider.
3Create a Cloud Firestore database and a Storage bucket.
4Copy your config object into // OURTUBE FIREBASE CONFIG at the top of this file, then reload.
